🐳 UISP Docker Deployment

Complete Docker Compose setup for Ubiquiti UISP with backup restoration

Key Features

  • Docker Compose orchestration
  • Persistent data volumes
  • Automatic backup restoration
  • Systemd-based container
  • Multi-port mapping
  • Security hardening guide

📖 Quick Start

Clone the repository and deploy to your VPS in minutes:

git clone https://github.com/asmd2268/uisp-docker.git
cd uisp-docker
cp /backup/file uisp-backup/
./deploy.sh
